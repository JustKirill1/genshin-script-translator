# Community glyph libraries

Glyph libraries (`.gsrlib`) shared by players. Import one in the app: *Tools → Import library…*.

## Sharing yours

1. In the app: *Tools → Export library…*, choose the scripts and enter your nickname.
2. Name the file `<nickname>-<script>.gsrlib` (e.g. `traveler-inazuma.gsrlib`).
3. Open a pull request adding it to this folder. Please only include glyphs you have checked:
   wrong samples make recognition worse for everyone who imports them.

# Библиотеки букв от игроков

Библиотеки букв (`.gsrlib`), которыми поделились игроки. Импорт в программе:
«Инструменты → Импорт библиотеки…».

## Как поделиться своей

1. В программе: «Инструменты → Экспорт библиотеки…», выбери письменности и укажи ник.
2. Назови файл `<ник>-<письменность>.gsrlib` (например, `traveler-inazuma.gsrlib`).
3. Создай pull request, добавляющий файл в эту папку. Добавляй только проверенные буквы:
   неправильные образцы ухудшат распознавание у всех, кто импортирует библиотеку.
